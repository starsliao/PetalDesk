# AMO 公开上架文案（zh-CN 草稿）

## 名称

飞花 - PetalDesk 浏览器增强

## 简短摘要

连接本机飞花桌面应用，在 Firefox 中完成长截图，安全填充或保存站点账号密码，并联动本地 TOTP。

## 完整介绍

飞花浏览器增强是飞花 - PetalDesk Windows 桌面应用的 Firefox 配套扩展。

主要功能：

- 对网页滚动区域执行长截图，保持现有飞花长截图工作流。
- 从飞花密码管理器打开登录页，用户在飞花中选择账户后填写用户名和密码。
- 识别用户主动提交的登录表单，并立即提示新增或更新飞花中的账户。
- 浏览网站时在工具栏角标显示该站点已保存的账户数；点击图标弹出连接诊断与当前站点账户列表，点击账户即可直接填充当前页并显示短暂结果提示。
- 将密码账户关联到一个本地 MFA 账户；账号密码填入后，可在受信任的登录流程中填入唯一明确的 6/7/8 位 TOTP 字段。模糊字段会先询问用户，跨站点 MFA 页面首次需要确认精确 HTTPS origin。
- 在工具栏账户卡片中分别复制用户名、密码或已关联的 MFA 验证码；验证码由桌面应用直接写入系统剪贴板，并在失效时自动清除。
- 允许用户为改版或内部站点录制受约束的字段模板；录制只保存选择器，不读取字段内容。
- 支持通用登录表单，以及 Google、Microsoft、阿里云、腾讯云和华为云的内置字段模板。

安全边界：

- 扩展必须连接本机已注册的飞花 Native Messaging Host；不会把数据发送到飞花或其他第三方服务器。
- 用户名和密码数据权限（authenticationInfo）为安装时一次性授予的必要权限；扩展不在运行时二次申请，也没有工具栏授权步骤。
- 密码填充只有在用户从飞花或工具栏弹窗主动选择账户后才会启动；后续关联 TOTP 仍须通过受信任的登录流程。扩展只填写字段，绝不自动提交表单。
- TOTP 联动只在飞花填入密码，或用户输入与唯一已保存账户完全一致时启动；恢复码、短信或邮件验证码、CAPTCHA、Passkey、安全密钥、CVV、邮编和优惠码不会被填入。
- MFA 密钥始终留在桌面加密保险库中。自动填入所需的当前验证码只在本机内存通道中短暂使用；工具栏复制 MFA 时验证码不经过扩展。
- 登录候选只在扩展内存中短暂保留，超时、断开连接或页面关闭后立即清除，不写入浏览器存储。
- HTTP 站点默认拒绝密码功能，必须在飞花中逐站点明确允许并持续显示风险提示。

密码保险库位于用户自己的 Windows 设备上，由飞花桌面应用加密保存。扩展不能独立读取保险库。

## 0.8.0 更新说明

- 密码账户可关联本地 MFA，并在受信任的登录流程中自动或经确认填入 TOTP，绝不主动提交表单。
- 工具栏账户列表改为固定卡片，提供复制用户名、密码、MFA 与二次确认删除。
- 密码保险库升级到 v2，并透明迁移 v1 数据。
