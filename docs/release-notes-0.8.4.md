## 主要更新

- 修复 Windows 远程桌面断开或重连后飞花可能整体无响应的问题。根因是托盘事件处理同步向 Explorer 查询通知区域图标矩形，RDP 会话切换期间该调用可能长期等待。
- 托盘点击、双击和悬停事件改用当前光标的本地锚点，不再从 UI 线程调用阻塞的 `Shell_NotifyIconGetRect`。
- 显示器、设备或系统设置变化时只重置本地悬停状态；任务栏重建时按需重新注册图标，两条路径都不在窗口过程内运行嵌套消息循环。

## 兼容与行为边界

- 现有托盘菜单、普通双击以及 `Alt` / `Ctrl` / `Shift` + 双击动作保持不变；飞花只使用鼠标按钮和修饰键，不依赖精确托盘图标矩形。
- 本次没有改变本地数据格式、存储路径、密码或 MFA 保险库，也没有增加浏览器权限或改变 Native Messaging 协议。
- Firefox 发布包随桌面版本统一升级到 `0.8.4`，扩展功能、安全边界和权限声明保持不变。

## 验证

- 已对真实托盘窗口连续发送 20 轮、共 80 条设备、显示、设置和任务栏重建消息，全部在超时前返回，压力测试前后句柄数保持稳定。
- 已通过本地托盘回归测试、Cargo 全目标检查、Svelte 检查、356 项前端测试、production 前端构建、Windows release 主程序与 Native Messaging Host 构建。
- 发布 CI 会同时检查 Cargo 实际解析到本地修复版 `tray-icon 0.24.2`，并确认最终 Windows EXE 未包含阻塞 API。
