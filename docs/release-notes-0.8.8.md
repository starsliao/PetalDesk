## 主要更新

- 新增 Windows「网络体检」小工具。点击查询即枚举本机全部 TCP 连接，给出连接状态总览、临时端口占用比、按进程聚合和按目标端点聚合，并研判本地代理环路。只读取连接元数据，不读取任何流量内容，也不写入诊断日志。
- 目标端点聚合解决了按进程看不出问题的场景：`TIME_WAIT` 在 Windows 上的属主 PID 是 0，几万条堆在一起也归因不到任何程序。飞花额外把回环目标的端口反查成监听方进程，这些无主连接因此能落到具体程序头上。
- 环路研判会在某个回环端点被大量打入、而它的属主进程自身出站又几乎全部回到本机时给出告警：这说明流量在两个程序之间空转，而不是真的发了出去。告警会同时点名环路双方和排在前面的上游调用者。
- 临时端口占用比按当前系统实际配置的动态端口范围计算，并分为正常、接近耗尽和危险三档。端口接近耗尽时任何程序都可能突然连不出去，且报错形式各异（DNS 失败、TLS 握手超时、推送卡死），很难直接联想到端口耗尽，因此单独列为一项。
- MFA 验证器的隐藏验证码旁新增复制按钮，不必再依赖双击整卡；复制过程中按钮显示进度并禁用，复制不会显示验证码。

## 便签选中与复制

- 修复跨行选中时选区变形、未选中的空白处也被染色的问题。此前 `drawSelection` 按行绘制的矩形选区与原生选区同时上色，半透明色叠加出更深的块，并把行尾空白一并染色。现在选区交给浏览器原生绘制，只有选中的文字才会高亮。
- 选中文字自动复制成功后，便签右下角会提示「已复制」。剪贴板写入被拒时不提示，避免让人误以为已经复制到。

## 故障诊断与假死修复

- 桌面进程默认把结构化诊断写入 Windows `%LOCALAPPDATA%\PetalDesk\logs\petaldesk-diagnostics.log` 或 macOS `~/Library/Application Support/PetalDesk/logs/petaldesk-diagnostics.log`，达到 1 MiB 后轮转并保留 3 份历史文件。日志记录版本、进程与会话信息、启动/窗口/托盘阶段、每分钟一次的句柄/线程/内存/CPU 趋势，以及主事件循环超过 15 秒未响应时的 Windows 等待链。
- 写盘、资源采样和等待链查询都在独立系统线程执行，正常事件记录不会让 UI 线程等待日志 I/O；进程退出时最多等待 250 ms 确认最后一条记录已写入。
- 诊断日志不记录便签标题或正文、便签 ID、数据目录、网址、用户名、密码、MFA/TOTP 密钥、剪贴板内容、浏览器消息正文、Cookie 或令牌。遇到假死请先保留进程现场，并保留当前日志及 `.1.log`、`.2.log`、`.3.log`，再决定是否结束进程。
- 本地修补并锁定 `tray-icon` 与 `tao` 两个依赖：`tray-icon` 原本对每次鼠标通知都同步调用 `Shell_NotifyIconGetRect`，远程桌面会话切换时 Explorer 可能停止响应该调用并阻塞 Tauri 的 UI 线程；`tao` 则在任务栏 COM 调用可能重入窗口过程之前提前释放窗口状态锁。

## 兼容

- 本次没有改变密码或 MFA 保险库格式、恢复密码、数据存储路径或跨设备恢复规则。
- `0.8.6` 与 `0.8.7` 未公开发布，其改动全部包含在本版本中；从 `0.8.5` 升级可直接覆盖安装。
- 网络体检为 Windows 独有，macOS 当前版本不提供。

## 验证

- 网络体检的聚合逻辑是与平台无关的纯函数，覆盖状态占比、临时端口去重与分档、无主 `TIME_WAIT` 归因、环路检出，以及两类必须不误报的场景：真实对外服务的繁忙本地端口，以及未达命中阈值的偶发本地调用。连接采集使用 `GetExtendedTcpTable`，在两万三千条连接的实测样本上约 200 毫秒返回，而 `Get-NetTCPConnection` 在同一样本上会超时并返回空表。
- 新增回归测试校验每个工具窗口的 label 都在 Tauri 能力白名单内。缺失时窗口仍能渲染、命令仍可调用，但关闭与标题栏拖动会被静默拒绝，编译与类型检查都发现不了。
- 便签选区改动有回归测试断言不再产生 CodeMirror 的绘制选区图层；复制提示分别覆盖写入成功与写入被拒两条路径。
