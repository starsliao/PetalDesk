## 主要更新

- 修复 Windows 开机启动设置可能因注册表权限返回“拒绝访问”的问题；设置错误现在固定显示在对话框顶部。
- 托盘入口改为“打开主界面”，便签操作合并为包含“新建便签”和现有便签列表的二级菜单。
- 关于页安全渲染更新内容中的 Markdown，标题、列表、链接和代码片段不再显示为原始标记。
- Firefox 弹窗的扩展状态默认折叠，四个状态点可快速概览安装权限、Native Host、桌面密码通道和登录检测。主界面、密码、MFA、便签四个入口调整到同一行。
- 从 Firefox 弹窗复制关联 MFA 后会显示真实剩余有效秒数；验证码到期不再因此自动清空系统剪贴板。

## 安全与行为边界

- MFA 验证码、MFA ID 和密钥仍不会返回扩展；本次复制响应只返回剩余有效秒数。
- 验证码过期只表示不能再用于认证。被其他内容替换前仍可留在剪贴板；主动锁定 MFA 或退出飞花时仍会清理未被替换的验证码。
- 登录检测正常时状态点为绿色，异常、重连中或未知时为红色，只有用户主动关闭后才显示黑色。断线仍会先自动快速重连 3 次，全部失败后才显示手动重连按钮。
- 密码与 MFA 填充仍不会点击按钮、发送 Enter 或主动提交表单，Firefox 权限没有增加。

## 验证

- 已覆盖 Rust、Svelte、Firefox 扩展、Windows updater manifest、macOS 构建脚本和 Firefox AMO 打包检查。
- Windows 安装包继续包含签名的自动更新载荷与 Native Messaging Host。
- macOS 继续提供 Intel 与 Apple Silicon 共用的 Universal DMG；本版本沿用未签名、未公证的构建状态。
