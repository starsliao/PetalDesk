飞花 Chrome / Edge 浏览器增强

Chrome 与 Edge 共用 Chromium 版扩展，并与 Firefox 版使用相同的工具栏弹窗、站点账户操作、登录保存提示、受控密码与 TOTP 填充，以及网页长截图增强。

下载 Chromium 扩展 ZIP 下载飞花桌面端

当前通过 GitHub 提供开发者模式 ZIP，尚未声称在 Chrome Web Store 上架。固定扩展 ID：eclmlkbklcpcaijloflmohfpeldcbjkp。

安装条件

  • Windows 10/11 x64 上安装飞花 - PetalDesk 0.8.8 或更高版本。
  • Google Chrome 109 或 Microsoft Edge 109，或更高版本。
  • 扩展目录需要长期保留；移动或删除目录后浏览器无法继续加载。

安装步骤

  1. 先安装或升级飞花桌面端。安装器会为固定扩展 ID 注册本机 Native Messaging Host。
  2. 下载 PetalDesk_Chrome_unpacked_0.8.8.zip，解压到不会移动的本地目录。
  3. Chrome 用户打开 chrome://extensions；Edge 用户打开 edge://extensions。然后开启页面中的“开发者模式”。
  4. 点击“加载已解压的扩展程序”，选择直接包含 manifest.json 的目录。
  5. 保持飞花运行，点击工具栏中的飞花图标检查 Native Host 和桌面密码通道状态。

Chrome 或 Edge 可能持续显示开发者模式提示，这是从 GitHub 加载未上架扩展的正常行为。请只使用本项目 Release 中的 ZIP。

工具栏功能

  • 查看扩展安装、Native Host、桌面密码通道和登录检测状态。
  • 为当前站点显示账户角标和账户卡片，点击卡片填充，分别复制用户名、密码或关联 MFA。
  • 通过右键菜单和二次确认删除账户。
  • 单独开关登录检测，或在自动重连失败后手动重连。
  • 打开飞花主界面、密码管理器、MFA 验证器或新建独立便签。

HTTP 与安全边界

登录检测覆盖 HTTP 和 HTTPS，因此在 HTTP 站点提交新账号或修改密码后也会提示保存或更新。HTTP 会在保存时明确提示明文传输风险，用户接受后仅为该精确 origin 允许后续填充。

扩展只填写字段，绝不点击登录按钮、发送 Enter 或主动提交表单。TOTP 仍只用于受信任的 HTTPS 登录流程。凭据不会写入 Chrome 或 Edge storage、扩展日志或截图文件通信目录，也不会上传到飞花服务器。
