浏览器增强隐私政策

飞花浏览器增强只与同一台 Windows 电脑上的飞花桌面应用通信，不运营云端账号，也不把浏览数据或凭据上传到飞花服务器。

最后更新：2026 年 8 月 5 日

适用范围

本政策适用于 Firefox 上的“飞花 - PetalDesk 浏览器增强”。它为飞花桌面应用提供长截图、经用户确认的密码填充，以及经用户明确授权的登录信息检测。

处理的信息

  • 长截图所需的网站活动数据，例如滚动位置、视口尺寸和页面稳定状态。
  • 用于把密码请求绑定到正确页面的精确网址 origin、标签页、文档和 frame 标识。
  • 仅在用户开启密码功能后处理的用户名和密码（所需数据权限已在扩展安装时作为必要权限确认）。

扩展不会为广告、分析或画像收集页面正文、完整浏览历史、付款信息、健康信息、位置或广告标识符。

使用方式

  • 长截图数据通过 Firefox Native Messaging 发送给本机飞花进程，用于完成用户主动发起的截图。
  • 密码填充先显示不含密码的页面确认提示。用户确认后，桌面应用才提供一次性凭据；扩展只填写字段，绝不自动提交表单。
  • 登录检测开启后，扩展把短时登录候选交给本机加密保险库判断是否完全相同、需要新增或需要更新。

扩展不会绕过验证码、Passkey、短信验证、安全密钥或多因素认证。

存储与保留

扩展不会把密码或登录候选写入 Firefox storage、磁盘或旧的截图文件通信目录。包含密码的登录候选最多在扩展内存中保留 30 秒；两步登录中的纯用户名阶段最多保留 2 分钟，只用于同一标签页和精确 origin 的下一步。它们都会在超时、页面关闭或连接断开时清除。填充完成或取消后，扩展立即丢弃相关消息引用。

用户选择保存的凭据由飞花桌面应用写入本地 XChaCha20-Poly1305 加密保险库，保留与删除由用户在飞花中控制。

传输、共享与安全控制

扩展不出售、出租或向远程第三方传输个人信息。Native Messaging 只连接当前 Windows 用户下注册的飞花本机程序。

  • 密码操作要求 scheme、主机和端口完全匹配，并绑定单次会话与目标页面。
  • 每次填充都需要页面内确认，且不会自动提交。
  • HTTPS 为默认要求；HTTP 必须在飞花中逐 origin 明确允许并持续显示风险提示。

用户选择与联系

身份验证信息权限为安装时的必要权限：用户可以在安装时拒绝（扩展将无法启用）、在飞花中关闭登录检测、手动锁定密码保险库、删除已保存账户，或卸载扩展。

隐私与支持问题请通过 PetalDesk GitHub Issues 联系项目维护者。

PetalDesk Browser Companion Privacy Notice

Last updated: August 5, 2026

PetalDesk Browser Companion communicates only with the PetalDesk desktop application on the same Windows computer. It has no PetalDesk cloud account and does not upload browsing data or credentials to a PetalDesk server.

Information handled and purpose

The extension handles website activity needed for user-initiated long screenshots; exact origins and tab, document, and frame identifiers needed to bind a password request; and usernames and passwords only after the user enables password features. The authentication-information permission is required and granted once at install time.

A fill offer contains no password. Credentials are requested only after the user confirms the in-page prompt. The extension fills fields but never submits a form. When login detection is enabled, a short-lived candidate is sent to the local encrypted vault to decide whether it is unchanged, new, or an update.

Storage, sharing, and retention

Credentials and login candidates are not written to Firefox storage, disk, or the legacy screenshot file bridge. Candidates containing a password remain in extension memory for no more than 30 seconds and are cleared on timeout, pagehide, tab close, disconnect, or a user decision. A username-only stage for a two-step login may remain for up to two minutes and is bound to the same tab and exact origin; it is cleared on timeout, tab close, disconnect, or a new origin. Saved credentials remain in the encrypted local PetalDesk vault.

The extension does not sell, rent, or remotely transmit personal information. Native Messaging transfers data only to the registered PetalDesk executable under the same Windows user account.

Controls and contact

Password operations require an exact scheme, host, and port match, a bound target page, and visible confirmation. HTTPS is required by default; HTTP requires a separate per-origin opt-in. The extension never bypasses CAPTCHA, passkeys, SMS verification, security keys, or MFA.

The authentication-information permission is required at install time. Users may decline it during installation (the extension cannot run without it), disable login detection, lock the password vault, delete accounts, or uninstall the extension. Questions can be filed through PetalDesk GitHub Issues.
