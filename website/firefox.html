飞花 Firefox 浏览器增强

同一个扩展提供网页长截图、站点账户数角标、连接诊断与账户弹窗，以及经用户确认的密码填充和登录信息保存提示。密码能力支持 Windows 与 Firefox Desktop 140 或更高版本。

在 Firefox Add-ons 查找 PetalDesk 下载飞花桌面端

首版 AMO 提交材料已准备，待发布者在 Developer Hub 完成最终提交。若安装链接暂时不可用，请稍后从本页重试。GitHub Release 中的 AMO-upload ZIP 用于商店审核，不能替代 AMO 签名安装。

安装条件

  • Windows 10/11 x64 上已安装飞花 - PetalDesk 0.6.0 或更高版本；密码角标、弹窗与登录检测需要 0.7.0 或更高版本。
  • Firefox Desktop 140 或更高版本；Android、Chrome 与 Edge 暂不提供密码能力。
  • 安装扩展时由 Firefox 显示权限，并由用户本人确认。

连接与授权

  1. 从 Firefox Add-ons 安装扩展，保持飞花桌面端运行；身份验证信息权限在安装时由 Firefox 一并确认，无需再次授权。
  2. 打开飞花密码管理器；标题栏显示“Firefox 已连接”后可以打开站点。
  3. 浏览网站时，工具栏角标会显示该站点已保存的账户数量；点击飞花图标可查看连接诊断和账户列表，点击账户即可在当前页发起填充。

安全边界

填充前页面会再次显示目标 origin 与账户名；扩展只填写字段，不会自动提交。登录候选仅在内存中短时保留，凭据不会写入 Firefox storage 或截图文件通信目录，也不会上传到飞花服务器。
