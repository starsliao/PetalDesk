飞花 Firefox 浏览器增强

同一个扩展提供网页长截图、站点账户数角标、连接诊断与账户弹窗，以及由用户点选账户触发的密码填充和登录信息保存提示。密码能力支持 Windows 与 Firefox Desktop 140 或更高版本。

在 Firefox Add-ons 查找 PetalDesk 下载飞花桌面端

首版 AMO 提交材料已准备，待发布者在 Developer Hub 完成最终提交。若安装链接暂时不可用，请稍后从本页重试。GitHub Release 中的 AMO-upload ZIP 用于商店审核，不能替代 AMO 签名安装。

安装条件

  • Windows 10/11 x64 上已安装飞花 - PetalDesk 0.8.0 或更高版本，以使用密码与本地 TOTP 联动、卡片式账户快捷操作、直接填充和登录保存提示。
  • Firefox Desktop 140 或更高版本；Android、Chrome 与 Edge 暂不提供密码能力。
  • 安装扩展时由 Firefox 显示权限，并由用户本人确认。

连接与授权

  1. 从 Firefox Add-ons 安装扩展，保持飞花桌面端运行；身份验证信息权限在安装时由 Firefox 一并确认，无需再次授权。
  2. 打开飞花密码管理器；标题栏显示“Firefox 已连接”后可以打开站点。
  3. 浏览网站时，工具栏角标会显示该站点已保存的账户数量；点击飞花图标可查看连接诊断和账户卡片。点击卡片主体填充，右侧图标分别复制用户名、密码与已关联的 MFA。

安全边界

用户在飞花或工具栏弹窗中点选账户后，扩展会校验目标标签页、顶层 origin、文档和登录 frame，再把一次性凭据交给目标字段；无需页面二次确认，也不会自动提交。密码账户可关联本地 TOTP：密码填入或唯一账户完全匹配后，唯一可信字段可自动填入，模糊字段需用户点击确认；跨 origin MFA 只接受首次确认的精确 HTTPS origin，跨 origin OTP iframe 拒绝。MFA 密钥始终留在桌面保险库，弹窗复制验证码由桌面端直接写入并在过期时清除。凭据不会写入 Firefox storage、日志或截图文件通信目录，也不会上传到飞花服务器。
